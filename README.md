# Netflix UI Clone

A responsive Netflix UI Clone built using HTML, CSS, and JavaScript. This project recreates the look and feel of the Netflix homepage with a modern and user-friendly interface.

# Live Website URL:

  https://amruthalahari2704-oss.github.io/Netflix-UI/

# GitHub Repository:

https://github.com/amruthalahari2704-oss/netflix-ui-clone/tree/main


# Project Purpose

The purpose of this project is to improve front-end web development skills by recreating a popular streaming platform's user interface.


# Features

- Responsive design
- Netflix-inspired user interface
- Navigation bar
- Hero section
- Movie and TV show cards
- Attractive layout and styling

# Technologies Used

- HTML5
- CSS3
- JavaScript
